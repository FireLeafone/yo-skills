## 0. 风格执行卡（1 页以内，写前必读）

### 0.1 一句话风格

冷峻白描 + 制度经济学解剖：残酷写成一张可核算的账单，战争写成器物、情报与组织的博弈，善意压缩到一块糖糕、一颗鸟蛋的剂量。

### 0.2 硬规则

- **视角**：第三人称，默认贴庞雨。他的内心用现代经济/管理/工程词汇；对话用明代语言。换场景用空行 +“……”+ 地点 + 一个物象/声音/温度；换视角只在地点/时间/阵营变化时。
- **主角**：每个场景先让他算账（钱、权、风险、人情），再让他做一点小额、具体、有代价的善。他靠算计、组织、信息取胜，不靠武力、先知、主角光环；他的判断允许被现实推翻。
- **语言**：叙述句 10–30 字为主；对话短、碎、带打断；动作多于形容词。现代术语只在叙述/内心，不进对话。每 1–2 章一处公文/账册/牌票/数字细节。
- **对话**：每个常设角色有“自称 + 口癖 + 句长”三件套；遮住名字要能认出谁在说。官场写“两本账”（台面道理 + 私下算计），用短问和沉默逼人；底层可以粗口、方言；敌方有自己的黑话。
- **场景**：一章 2–4 个场景；每个场景结束要有可量化的状态变化（钱、差事、地盘、情报、生死）。制度压迫按“牌票→执行链→受害者→冷判词”写；战斗按“部署→敌方误判→交手→器物出岔”写。
- **情感**：情感高点用陈述句和动作，不用感叹句；悲悯只用物件/动作表达。残酷场景配一个冷幽默/荒诞细节；温情一笔即收。
- **禁止**：现代词汇进对话；连续三句纯设定；主角开挂/反派降智；战争开图碾压；残酷苦情化/血浆化；伏笔回收点破；配角同腔同调；感叹句抒情/作者说教。

### 0.3 本章写作流程

1. 定本章核心任务：这一章结束时，谁的处境发生了什么变化？
2. 定 2–4 个场景：每场景写清时间、地点、视角人物、冲突、状态变化。
3. 按「5. 场景配方」写；每写完一个场景，跑一次局部自检。
4. 章末停在具体画面、具体问题或一句会被打脸的话上，不写总结。
5. 交稿前跑「7. 写时自检清单」和「8. 防跑偏」。

## 1. 叙述视角与信息边界

### 写的时候

- 默认第三人称，贴庞雨；他的内心用现代分析语言（成本、收益、风险、垄断、流程、工程），对话用明代语言。
- 每场戏先定“这场戏谁的眼睛”；场景内可以短暂进入配角内心，但只给一两句态度/算计，不展开长篇心理。
- 换场景：空行 +“……”+ 地点 + 一个物象/声音/温度；不写“与此同时”“话分两头”。
- 换视角：只在地点/时间/阵营变化时；敌方视角用来展示“基于不完整情报的合理误判”。
- 叙述者可以解释制度怎么运转、下冷判词（“从……的那一刻起……”），但不能提前泄露人物不知道的具体情节。

### 不要

- 不要在场景中途换头；不要用过渡总结；不要让叙述者替人物抒情；不要用全知视角剧透。

### 自检

- 这一段的视角人物是谁？他此刻知道什么、不知道什么？
- 删掉叙述者的解释，人物的决策还成立吗？

> 例文依据：第 58 段“放在后世就是扶贫对象”、第 236 段“大概类似警察局长”、第 388 段“……”后切敌方、第 48/269/302 段的“地点 + 物象”开场、第 109 段冷判词。

## 2. 主角决策引擎

### 每个场景先问

1. 他在这里能算出什么账？（钱、权、风险、人情）
2. 他能负担得起多少善？（通常很小，且不危及前途）
3. 他这次可能怎么误判？（基于不完整信息，做出合理但错误的判断）

### 行为规则

- 对上位者：圆滑、具体、带奉承；内心 OS 冷静拆账。给唐为民送靠背时说足漂亮话（例文第 159 段），心里算的是柜夫差事（第 205–208 段）。
- 对苦难：先用“我只是小人物”“不要让他们在你心中个体化”自我保护（第 80、93 段），再做一点小额善事：一块糖糕（第 113–118 段）、六钱银子的粮价（第 342 段）。
- 对暴力：允许他有“安全的兴奋”（第 473 段），但紧接着让现实打脸（第 538 段火雨烧悬帘）。
- 对胜利：靠组织、信息、器物、人情，不靠武力/先知；他挑不动一百多斤的粮担（第 336 段）。
- 对失败：会害怕、会贪小便宜、会判断错；不要让他料事如神。

### 不要

- 不要让他道德觉醒；不要让他见一个帮一个；不要让他用现代知识碾压古人；不要让他说现代术语。

### 自检

- 他在这段里付出的成本是什么？如果什么都没付出，就重写。
- 他的判断有没有可能错？如果不可能错，就说明开挂。

## 4. 语言执行参数

- **句长**：叙述句 10–30 字为主；对话 3–15 字；紧张段更短，解释段可长，但不超过 3 句无人物动作。
- **用词**：现代白话叙述 + 明代制度词 + 市井口语。不用“汝、吾、尔、岂、乎、也”的仿古文；不用网络梗。
- **现代术语**：只用于叙述/庞雨内心；每段最多 1–2 个；对话禁用。例：第 58 段“扶贫对象”、第 148 段“货币化补贴”、第 154 段“人体工学”、第 236 段“警察局长”、第 316 段“价格联盟”、第 317 段“经济动机”。
- **数字/文献**：数字具体到钱/分/斤/亩/人；每 1–2 章一处公文/账册/牌票；数字后面跟一个动作或后果。例：第 24–26 段牌票、第 204 段“桐城四十七里”“每里设一柜”、第 295 段“皂隶工食银六两，马快工食银十六两有余”。
- **暴力**：按“力→接触→材料反应→身体反应→后续动作”写；不写“惨”“血肉横飞”。例：第 361 段箭头路径、第 371 段“这些箭支虽然看着飞得快，却大多缺乏力道，即便命中也难以贯穿入肉”。
- **比喻**：少而实；一段最多一个；喻体来自日常/器物/军事，不来自网络/流行文化。例：第 372 段“如同小型标枪一般”。
- **段落**：对话和动作多用短段；制度解释用长段；形成“短—短—长”的呼吸。
- **禁止**：现代词进对话；连续三句纯设定；形容词堆砌；感叹句抒情。

### 自检

- 这段有没有连续三句纯设定/纯解释？
- 这段的现代术语，有没有跑进人物对话？

## 5. 场景配方

> 每类场景按“目标 → 节拍 → 视角 → 语言 → 正例 → 反例 → 自检”使用。正例/反例均为新写（非原文），只演示机制。

### 5.1 制度压迫 / 征收场景

- **目标**：让读者理解“不是某个坏人，而是整套流程在吃人”。
- **节拍**：
  1. 一纸文书/一个数字开场（牌票、借据、税单）。
  2. 执行链上的人依次出场，每人都有一笔账。
  3. 受害者只给一两个身体细节，不给大段哭诉。
  4. 主角在旁边算账/观察，不急着救人。
  5. 用一句冷判词收束（“从……的那一刻起……”）。
- **视角**：庞雨或执行者；不要切到受害者内心太多。
- **语言**：数字具体；行话准确；叙述冷。
- **正例（生成，非原文）**：“河工银的告示贴在祠堂门口，陈四喜不识字，只听里正念到‘每亩三分’，便蹲在墙根下算：他家七亩水田，该是二钱一分。里正又念，‘上田’改按‘下田’算，每亩另加一分工食。陈四喜还没算清，书吏已经把册子摊开，指着他的名字说，去年你家的田界挪过，得先交二钱‘丈量费’。他张了张嘴，想说自己从没挪过田界，书吏已经把笔递过来，让他在名字下面按个手印。陈四喜按了。从手印落下的那一刻起，他家那七亩水田就成了册子上的一块墨，想怎么写，全看拿笔的人。”
- **反例**：“陈四喜跪在地上嚎啕大哭，里正和书吏狞笑着逼他交钱，围观的乡亲们敢怒不敢言。陈四喜心中悲愤交加，暗暗发誓一定要讨回公道。”
- **自检**：读者能不能算出受害者的损失？坏人有没有自己的成本账？

### 5.2 官场对话 / 权力场景

- **目标**：写“两本账”和权力差，不写脸谱化贪官。
- **节拍**：
  1. 台面上的一句官话/原则。
  2. 下属的试探/推诿。
  3. 上司用一个短问/沉默逼人。
  4. 下属的低头/改口/沉默。
  5. 叙述者给一句冷静的内心账（仕途/成本/风险）。
- **视角**：以上司或旁观者为主；不要同时给所有人内心。
- **语言**：官场套话 + 短问 + 动作；少用“他说”。
- **正例（生成，非原文）**：“知县把茶盏搁下，问：‘河堤上那具尸首，仵作怎么报的？’典史低头道：‘回大人，说是失足落水。’知县没接话，只拿指节在桌面上轻轻敲了两下。典史的后颈便有些发潮，又补了一句：‘不过尸首头上有一处磕伤，仵作说，也可能是落水时撞的。’知县这才抬眼：‘撞在何处？’典史的声音低下去：‘说是……撞在河堤的石阶上。’‘石阶在岸上，尸首在河里。’知县把茶盏推到他面前，‘你再去问一遍。’”
- **反例**：“知县义正词严地说：‘本官绝不能容忍这种草菅人命的恶行！’典史羞愧地低下头，表示一定严查到底。”
- **自检**：台面话和心里账有没有同时出现？权力差是不是通过“谁问、谁沉默”体现的？

### 5.3 市井对话 / 信息释放场景

- **目标**：用对话交代制度/情报，同时塑造人物。
- **节拍**：
  1. 一个具体的生活动作开场（擦汗、搬粮、数钱）。
  2. 一个外行问“外行问题”，另一个用行话解释。
  3. 主角内心用现代逻辑翻译一遍。
  4. 主角据此做一个决定/行动。
  5. 结尾留一个信息缺口或人情债。
- **视角**：庞雨 + 一个信息提供者。
- **语言**：行话 + 方言 + 短句；解释不超过 3 句。
- **正例（生成，非原文）**：“新来的帮闲问：‘这鱼鳞册上明明写着十亩，怎么他家只认六亩？’老书手把册子往他面前一推：‘你看见的是十亩，衙门看见的是六亩，中间那四亩，得有人替它交税。’‘谁替它交？’‘谁的名字写在册子上，谁交。’老书手用指甲在一行小字上划了一道，‘这叫飞洒。田还是那块田，税还是那些税，只是从这家的册子，飞到那家的册子上。’新来的帮闲听得半懂不懂，老书手又补了一句：‘你只要记住，册子上的字，比田里的土值钱。’”
- **反例**：“老书手详细地解释道：‘飞洒是明代赋役制度中的一种常见弊端，指的是将田亩分散记入他人户下，以逃避赋税……’新来的帮闲恍然大悟。”
- **自检**：这段对话有没有同时完成“给信息”和“立人物”两件事？

### 5.4 战斗 / 守城场景

- **目标**：写“迷雾 + 器物 + 组织”，不写“武侠”。
- **节拍**：
  1. 部署：双方看到什么、误判什么。
  2. 敌方会议：合理但错误的判断。
  3. 交手：器物按物理规律运作；第一波可能是弱旅。
  4. 出岔：前文埋的技术妥协/误判发作。
  5. 收束：一个具体画面/数字/下一波威胁。
- **视角**：守方主角 + 敌方主帅；不要全知。
- **语言**：器物名词 + 数字 + 短句；暴力写过程。
- **正例（生成，非原文）**：“城下的云梯第三次搭上来时，李守备没有看梯子，先看城垛后面的水缸。昨夜他让人把水缸挪到女墙内侧，缸沿上结了薄冰。‘泼。’他说。水顺着梯子浇下去，下面的人还在往上爬，脚底一滑，最上面那个便挂在半空，被城头的钩镰枪勾住衣领，整个人翻了下去。梯子没有倒，反而往右一偏，搭在了两丈外的垛口上。李守备骂了一声，转头喊：‘西段还有人没有？’没人应。他这才想起，西段的顶杆昨天被抽去修城门，只剩三根。”
- **反例**：“李守备大喝一声，挥舞长剑冲上城头，一剑砍翻了三个敌人。敌军见状，纷纷胆寒后退。”
- **自检**：这段的胜负手是部署/器物/情报，还是主将武勇？

### 5.5 场景转换 / 章节开头

- **目标**：硬切、定调、带入，不写过渡总结。
- **节拍**：
  1. 上一场景停在动作/台词。
  2. 空行 +“……”+ 地点 + 一个物象/声音/温度。
  3. 新场景第一句就带冲突/信息。
- **视角**：新场景的视角人物。
- **语言**：第一句要能“拍”出来；不要解释。
- **正例（生成，非原文）**：旧场景结尾：“他把册子合上，说散了吧。”新场景开头：“……河湾的盐船上，雨把船篷敲得像炒豆。船头的人把最后一块盐包压进舱底，才看见岸上来了两匹马。”
- **反例**：“与此同时，在河湾的盐船上，另一个人也在想着同样的事情。”
- **自检**：新场景第一句有没有地点 + 物象？删掉过渡句，读者会不会迷路？

### 5.6 章末钩子 / 情感落点

- **目标**：让读者想翻下一章，或让情感落在物件上。
- **四种钩子**：
  1. 新问题/新案件（例文第 227 段“刚出的命案”）。
  2. 具体画面/草标（第 352 段）。
  3. 一句会被打脸的话（第 477 段“流寇也没啥大不了的”）。
  4. 灾难降临的画面（第 545 段“漫天火雨”）。
- **节拍**：本章冲突收束 → 一个具体画面/一句话 → 不解释。
- **视角**：主角或本章视角人物。
- **语言**：短；画面感；不要总结。
- **正例（生成，非原文）**：“他刚走出门，就看见门槛上放着一只旧布鞋。鞋底磨穿了，鞋帮上沾着泥，像是从很远的地方走来的。他弯腰去捡，才发现鞋里塞着一张折好的纸——是今早他在堂上按过手印的那张。”
- **反例**：“他心中充满了对未来的担忧，不知道明天会发生什么。”
- **自检**：章末停在画面/问题/打脸句，还是总结/抒情？

## 6. 伏笔与信息释放

### 埋

- 用温情/滑稽/技术妥协/主角误判伪装。例：糖糕与鸟蛋（第 118、138 段）、干棉被悬帘（第 422、538 段）。
- 每个主要配角登场时，带一个当时看似无关的身份/性格细节，留待数章后激活。
- 让主角基于不完整情报做一个合理但错误的判断（第 477 段）。

### 收

- 回收只给画面/后果，不解释、不点破。例：第 352 段“身后插着一个草标”、第 538 段“这样一个疏忽，在此时酿成了恶果”。
- 回收依据必须是前文已给的信息，不天降新设定。

### 信息释放

- 三拍：对话给出 → 主角内心翻译 → 据此决策。例：飞洒（第 130–134 段）、官吏分途（第 169–174 段）。
- 战斗/对抗：双方各一份不完整情报；读者知道双方之和，但不知道结局（第 396–399 段敌方判断；庞雨据灯海光晕估“必定超过四万人”）。
- 真相：由配角滞后补全（岳季命案：第 237–238 段官方版本 → 第 309–317 段经济逻辑）。

### 禁止

- “原来”“没想到”这类点破词；伏笔埋得太明显；叙述者一次讲完。

### 自检

- 这个伏笔埋的时候像不像闲笔？回收时有没有解释过头？
- 读者现在知道什么、人物知道什么？信息差是不是有意设计的？

- [ ] 这一段的视角人物是谁？他此刻知道什么、不知道什么？
- [ ] 这段有没有让主角算账？他付出的成本是什么？
- [ ] 这段的善意是否小额、具体、有代价？
- [ ] 这段有没有现代词进对话？
- [ ] 这段的对话遮住名字能认出谁在说吗？
- [ ] 这段有没有连续三句纯设定/纯解释？
- [ ] 这个场景结束时，什么状态发生了变化？
- [ ] 这个场景的冲突来自制度/利益，还是来自“坏人”？
- [ ] 这段暴力是否写了物理过程，而不是“惨”？
- [ ] 这段有没有一个冷幽默/荒诞细节来中和残酷？
- [ ] 这段的伏笔是否伪装得够自然？回收是否没有点破？
- [ ] 章末钩子是否具体（画面/问题/一句会被打脸的话）？
- [ ] 这段有没有感叹句抒情/作者说教？
- [ ] 这段有没有让主角开挂/反派降智/战争开图？
- [ ] 这段删掉后，情节还推进吗？不推进的话有没有情绪功能？

## 8. 防跑偏

- 【跑偏点】把考据写成制度说明书
  - 典型表现：连续几段讲一条鞭法、鱼鳞图册、官吏分途，人物只是站着听课。
  - 自检问题：这一段谁得利、谁倒霉？
  - 修正动作：把制度披露挂到正在发生的利益事件上；超过三句没有人物利害的设定，删到一句或拆进对话。

- 【跑偏点】现代词汇进对话
  - 典型表现：明代衙役说“性价比”“垄断”“内卷”，叙述者在严肃场景玩网络梗。
  - 自检问题：引号里有没有现代术语/网络词？
  - 修正动作：现代术语只留在叙述/主角内心；对话换成当时的行话（“羡余”“折色”“牌票”“工食银”）。

- 【跑偏点】把庞雨写成爽文男主/道德完人
  - 典型表现：该忍时亮剑、靠现代知识碾压古人、反派降智、见人受苦就大把撒银。
  - 自检问题：他这段付出的成本是什么？
  - 修正动作：每次得利先写成本（送礼、陪笑、风险、良心不安）；善意改成小额、具体、有代价；该吃瘪就吃瘪。

- 【跑偏点】战争写成开图碾压/个人英雄主义
  - 典型表现：主角料事如神、部署全部兑现、敌军按剧本送死、主将单挑逆转。
  - 自检问题：这段的胜负手是部署/器物/情报，还是主将武勇？
  - 修正动作：给双方各一份有缺陷的情报；让主角的判断被前文埋的技术细节推翻；敌方加一场合理但错误的决策会议。

- 【跑偏点】残酷写成苦情戏或血浆片
  - 典型表现：催缴场面大段哭嚎、守城死伤用排比感叹句；或为猎奇详细展示伤口。
  - 自检问题：这段是在算账/写流程，还是在替读者哭/展示伤口？
  - 修正动作：残酷用“流程 + 物证”呈现；暴力用物理过程呈现；每场残酷配一个冷幽默/荒诞细节；情感高点改陈述句。

- 【跑偏点】善意泛滥，温情拖长
  - 典型表现：庞雨见一个帮一个，银子和道理一起撒；温情戏写满半章。
  - 自检问题：这份善意花了他什么？如果什么都没花，就砍掉一半。
  - 修正动作：善意遵守“小额、具体、不危及前途”；一次只给一个物件/一句话/一个动作；温情一笔即收（“突然住口”）。

- 【跑偏点】配角同腔同调、沦为工具人
  - 典型表现：衙役、里长、书手全是一个口吻的势利眼；反派为恶而恶没有账本；敌方主帅是脸谱化蠢贼。
  - 自检问题：遮住名字，能认出是谁在说吗？
  - 修正动作：每个出场两次以上的配角配齐“自称 + 口癖 + 句式”三件套和一条利益动机；让对方阵营有自己的黑话。

- 【跑偏点】伏笔当反转写、回收时点破
  - 典型表现：埋笔时就暗示“这东西以后有用”；回收时让角色惊呼“原来是你”。
  - 自检问题：埋的时候像闲笔吗？收的时候有没有解释？
  - 修正动作：伏笔伪装成温情/滑稽/技术妥协；回收只给画面/后果；删掉“原来”“没想到”。

- 【跑偏点】时代温度只剩背景板
  - 典型表现：小冰河、白银外流只在开头交代一次；后面换成架空县城也成立。
  - 自检问题：删掉环境句，人物决策还成立吗？
  - 修正动作：把宏观危机折算成粮价、利息、税额、工食银、兵力数字渗入场景；写压迫写“流程”不写“惨状”。

- 【跑偏点】转场和节奏失真
  - 典型表现：该硬切的地方写过渡总结；该慢的地方一笔带过；把“句子短”当成“节奏快”。
  - 自检问题：这个场景结束时什么变了？删掉这一段，情节还推进吗？
  - 修正动作：一章 2–4 次硬切，用“……”+地点+物象；每个场景必须有可量化的状态变化；不要用短句冒充快节奏。

## 9. 适用场景与内置风格

- **适合**：历史穿越（尤其明清易代、制度崩坏题材）、官场 + 种田 + 经济混合流、底层小人物求生视角、硬核考据支撑的经济/财政戏、群像戏、冷幽默与残酷并置的市井场景、冷兵器守城战与情报驱动的会战。
- **慎用**：纯爽文节奏（本书慢热，主角长期吃瘪）、大团圆或热血救世基调、以浪漫爱情为主线的场景、个人武勇决定战局、朝堂高层政治与大规模野战（例文未覆盖）。
- **接近**：`style-guide.md` 的“叙事陈述”（信息密度、纪实感）为基底，混合“场面宏大”（多视角战争/群像）与少量“自然人声”（市井对话）。
- **差异**：比“叙事陈述”更冷、更脏、更具体，对话占比更高；与“网文爽感”正面冲突；与“感人煽情”冲突；与“古风文言”不同——它用现代白话叙述 + 明代制度词 + 市井口语，不追求典雅文言。
- **用法**：把本文件路径作为 `novel-write` 的风格参考传入，或复制到 `novel-write/references/` 供长期引用；历史题材可叠加 `rule-history.md`。

## 附录 B：技巧索引

> 以下技巧的完整机制和原作证据保留在这里；正文场景配方已把它们转成写作动作。本附录是索引，完整正例/反例/自检见对应场景配方（5.1–5.6）。原作片段只引用例文真实句子，生成示例均为新写。

### 用制度流程写残酷

- 原作片段：“从牌票发出的那一刻起，孙家的命运就已经注定。”——例文第 109 段。
- 机制：先写牌票/执行链/每环的账，再用一句冷判词收束；读者被“账算得过来”吓到，而不是被哭声打动。
- 写作动作：见 5.1；冷判词一章最多一次。

### 用实物承载情感

- 原作片段：“嘴中那一点糖糕抿了又抿，不舍得吞下去。”——例文第 118 段；“叔给了甜的，娘说要懂报恩，我自己拣的带鸟蛋（注：秧鸡），给叔吃！”——第 138 段。
- 机制：不写“感动/感激”，只写物件怎么被捧、抿、藏、递；一给一还，建立人情债，为后文草标埋账。
- 写作动作：选一个便宜、具体、可交换的小物件；写物理处理；不写情绪标签；后文以另一种形态回收。

### 用现代术语做叙述滤镜

- 原作片段：“放在后世就是扶贫对象”——例文第 58 段；“价格联盟”——第 316 段；“经济动机”——第 317 段。
- 机制：现代术语只在叙述/庞雨内心出现，人物对话仍用明代词汇；形成“穿越者滤镜”和“读者翻译器”。
- 写作动作：一段最多一两个；每次用术语解释一个具体明代现象，随后立刻回到动作/对话；对话里的人物必须用他们的词。

### 用工艺化白描写暴力

- 原作片段：“箭头摧枯拉朽般砸飞女贼满口门牙，又从口腔内破开女贼脸颊，箭身在脸肉上摩擦前行，直到能量耗尽，最后便挂在了女贼脸上，箭尾的羽毛刚好卡在女贼嘴唇上。”——例文第 361 段。
- 机制：把暴力拆成“力→接触→材料反应→身体反应→后续动作”；写旁观者的预期与物理事实的落差。
- 写作动作：见 5.4；关键场面用一次，不要每场都写成解剖课。

### 用技术妥协埋伏笔

- 原作片段：“棉被加水之后重达数百斤，会很快把木架压垮，于是便直接将干的挂在上面，同样能起到防箭的作用，这样一个疏忽，在此时酿成了恶果。”——例文第 538 段。
- 机制：先给装置功能/原理，再给一个“缺料/缺钱/缺人”的妥协；后文用相反场景攻击这个妥协；回收只补一句，不闪回。
- 写作动作：见 5.4；妥协必须合理，不能是作者为反转硬塞的蠢决定。

### 用敌方视角制造战争迷雾

- 原作片段：“六个管队守不住城门片刻，这城中怕是有官军。”——例文第 396 段；“不见得比庐州好打，又没有内应，平白死些人。”——第 399 段。
- 机制：敌方有独立会议、情报、分歧和权力关系；他们的判断“合理但错误”，读者知道守方准备，形成戏剧反讽。
- 写作动作：见 5.4；敌方不能全知，也不能全蠢。

### 用“两本账”和短问/沉默写官场

- 原作片段：“我等虽只牧守一县之地，然万千生灵在焉，都是我等衣食父母。”——例文第 249 段；“最好的办法，是应付一下安庆府和分巡道，然后拖到新知县上任，让那个新知县去头痛。”——第 264 段；“那可搜查吴府？”——第 258 段。
- 机制：公开话术与私下算计并置；短问句逼人；沉默/低头比辩解更能说明权力差。
- 写作动作：见 5.2；不要让叙述者骂他虚伪。

### 用“……”和感官锚点硬切场景

- 原作片段：“……南塘里孙家坝，村庄中传来阵阵狗吠。”——例文第 48 段；“……南大街吴家大门外人山人海。”——第 302 段；“……桥对面的城楼下，摆着一具红色的尸体。”——第 388 段。
- 机制：转场不写“话分两头”，只用“……”+地点+一个具体物象；开场句同时交代地点和定调。
- 写作动作：见 5.5；一章 2–4 次，不要每段都硬切。
