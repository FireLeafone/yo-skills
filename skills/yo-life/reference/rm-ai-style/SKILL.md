# 去除 AI 写作痕迹

识别并改写空洞、模板化和不自然的表达。目标不是规避检测，也不是把所有文字口语化，而是在保留事实和作者声音的前提下提高文本质量。

## 输入与边界

- 没有待改文本时，直接向用户索要，不生成示范来代替处理。
- 先识别体裁、目标读者和原文语气；用户指定的风格优先。
- 保留事实、数字、引文、条件、限制和不确定性，不改变核心信息。
- 不得为“更鲜活”新增来源、功能、用户反馈、个人经历或原文没有的观点。
- 只有原文已有第一人称，或用户明确要求加入其真实声音时，才使用“我”和个人感受。
- 对事实型、技术型内容，准确和自然优先于个性；小说可保留人物与叙述者的声音。

## 工作流程

1. **通读原文**：确定体裁、受众、语气和必须保留的信息。
2. **定位问题**：按 [AI 写作痕迹模式清单](references/ai-patterns.md) 检查内容、语言、结构、排版和沟通痕迹。该清单不是机械禁词表，正常且准确的用词不必替换。
3. **重写问题片段**：优先删除空泛内容、恢复具体主谓关系、调整节奏；无法补实的内容不要编造。
4. **复核保真**：逐项核对事实、因果关系、否定、程度和引用，确保没有遗漏或新增。
5. **复核自然度**：检查句式变化、段落节奏、语体一致性和残留的模板表达。
6. **交付**：先给完整重写文本，再按下方标准评分；只有有助于用户理解时附简短修改摘要。

## 核心原则

1. **删除填充**：去掉不提供信息的开场、强调和连接词。
2. **打破公式**：避免反复使用二元对比、三段式、倒装句、戏剧性分段和通用积极结尾。
3. **变化节奏**：按内容混合长短句，不为变化而制造碎句。
4. **信任读者**：减少过度解释、辩解和手把手引导。
5. **删除假金句**：听起来适合引用却没有信息量的句子应改成实质表达。
6. **保留真实声音**：不把每篇正式文本都改成随意、尖刻或带第一人称的文章。

## 个性与灵魂

个性来自具体观察和真实立场，不来自虚构经历。

- 原文有观点时，让它清楚、准确，而不是中立地堆叠利弊。
- 原文有复杂感受时保留层次，不强行增加情绪。
- 允许符合体裁的自然结构，不追求每段同样整齐。
- 具体化只能使用原文已有信息或用户补充的真实材料。

## 输出格式

```markdown
<重写后的完整文本>

## 质量评分
| 维度 | 得分 | 简要依据 |
| --- | --- | --- |
| 直接性 | /10 | ... |
| 节奏 | /10 | ... |
| 尊重读者 | /10 | ... |
| 声音与保真 | /10 | ... |
| 精炼度 | /10 | ... |
| 总分 | /50 | ... |
```

评分用于发现残留问题，不代表对“AI 检测率”的承诺。低于 35 分时先重新修订再交付；事实或原意发生变化时，无论总分多少都必须修正。
