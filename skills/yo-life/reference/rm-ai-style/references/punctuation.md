> - **第二层「每个标点干什么」**(其后各节):标点功能分工。SKILL.md 只保留结论性规则,细节都在这里。

## 中文正文一律用全角（第一层 · 用对字符）

在中文上下文里,**所有标点符号用全角**,不能和半角混用。这是最容易被忽略但也最明显的 AI / 机翻痕迹:英文训练数据里标点全是半角,模型输出中文时常常直接复用,读起来就会有"翻译腔"的视觉信号。

**对照表（含 Unicode 码位，避免视觉混淆）：**

| 场景 | 半角（错） | 全角（对） |
|---|---|---|
| 逗号 | `,` (U+002C) | `，` (U+FF0C) |
| 句号 | `.` (U+002E) | `。` (U+3002) |
| 冒号 | `:` (U+003A) | `：` (U+FF1A) |
| 分号 | `;` (U+003B) | `；` (U+FF1B) |
| 问号 | `?` (U+003F) | `？` (U+FF1F) |
| 感叹号 | `!` (U+0021) | `！` (U+FF01) |
| 括号 | `( )` (U+0028/U+0029) | `（ ）` (U+FF08/U+FF09) |
| 双引号 | `" "` (U+0022) | `“ ”` (U+201C/U+201D) 或 `「 」` |
| 单引号 | `' '` (U+0027) | `‘ ’` (U+2018/U+2019) 或 `『 』` |
| 破折号 | `-` / `—` | `——`（双长破折号，占两字宽） |
| 省略号 | `...` | `……`（双六点，占两字宽） |
| 顿号 | `,`（多数 AI 输出误用） | `、` (U+3001) |

**例外（保留半角）：**

- 代码块、变量名、函数名、命令内部：`foo(x, y)`、`git push`
- URL、文件路径、邮箱：`https://example.com/path?q=1`
- 版本号、数字、单位比较：`v1.0.0`、`< 200 字`、`30%`
- 行内英文短语内部：英文句子自身的标点按英文规则走
- Markdown 列表编号：`1.` / `2.` / `3.` 仍是半角

**典型错误：**

- 错:`这段文字是 AI 写的, 不是人写的.` ← 半角逗号、半角句号
- 对:`这段文字是 AI 写的,不是人写的。`
- 错:`他说: "我不知道".` ← 半角冒号、半角句号
- 对:`他说:"我不知道"。`
- 错:`工具 (如 Claude Code) 支持中文` ← 半角括号夹中文
- 对:`工具(如 Claude Code)支持中文`
- 错:`这个工具很好用 — 除了偶尔卡顿` ← 半角 em dash 作英文式插入
- 对:`这个工具很好用,就是偶尔会卡顿。` 或 `这个工具很好用——偶尔会卡顿`（全角双破折号）

### 破折号的密度基线

破折号 `——` 在**真人中文日常写作里的基线频率接近 0**, 这是它作为 AI 腔信号特别可靠的原因。三条结构性证据:

1. **输入成本高：** 规范 `——` 需要两个 U+2014 字符组合,多数中文字体渲染时中间留缝（知乎《文心雕虫·我们可能都不会打破折号》有详细讨论）。真人在微信 / 朋友圈 / 公众号 / 小红书环境里打出合规 `——` 是**高摩擦动作**,本能回避。
2. **教学惯例克制：** 中小学语文和《人民日报》杜老师信箱都把破折号定性为**特殊符号**,明确建议"一旦用得过多就会丧失阅读流畅感"。
3. **真人有零成本替代：** 插入 / 补注 / 转折 / 强调,真人更常用 `,` `(` `:` `。另起一句`—— 都是零成本字符。破折号只在**书面语、杂文、特稿、小说对话** 这些**明确承担修辞功能**的场景出现。

AI（尤其 ChatGPT / DeepSeek / 早期 Qwen / GLM）从**英文 pretraining corpus** 继承了 em-dash 高密度习惯（19 世纪英文书 + Medium 自动转换的组合效应）,中文输出里密度反常。英文媒体称这种残留为 `ChatGPT hyphen`（Sam Altman 2025-11 才在 X 上承认是 bug 并推修复）。**跨模型观察**：Claude 和 Gemini 相对克制,ChatGPT / DeepSeek / 早期 Qwen 密集。

**这是为什么本 skill 对非杂文 / 非特稿 / 非小说对话场景的破折号持默认怀疑态度。** #16（同位补注形状触发）和 #25（纯频率触发）的阈值都按这条基线校准。

**全角标点前后不加空格：** 全角标点自带视觉宽度,不论原文是否采用中英空格风格,**全角标点相邻处不加空格**:

- 对:`这是中文版,只支持简体。`
- 错:`这是中文版 , 只支持简体 。`（全角逗号、句号前加空格）
- 对:`这是中文版(只支持简体)。`
- 错:`这是中文版 ( 只支持简体 ) 。`（全角括号前后加空格）

## 顿号「、」vs 逗号「,」：并列一律顿号，不让逗号代劳

- **顿号：** 并列的词、并列的短语、并列的名词。`苹果、梨、香蕉` / `降低成本、提升效率、改善体验`
- **逗号：** 句子内部的停顿、分句连接。`我去买了水果,然后回家。`

**AI 常见误用：** 并列项用逗号(`苹果,梨,香蕉`)。根源是英文只有一个 `,`,训练数据里顿号 / 逗号的分工信号弱。

**严肃媒体基线：**《财新周刊》2026 封面报道里把三项并列政策写成「有效增加低收入群体收入、提高中等收入群体比重、推动形成橄榄型分配格局」—— 三项并列短语一律顿号,是教科书示范。

## 分号「;」：排比句群的节奏工具,语体敏感

分号跟破折号不同,**不是所有语体里高密度分号都是 AI 腔**,需要分层看。

> ⚠️ **语体分层触发：**
>
> - **日常 / 自媒体 / 社交 / 群聊**：分号基线接近 0,高密度基本是 AI 腔（英文 semicolon 习惯残留）。改用句号或逗号。
> - **社论 / 时评 / 长议论**：分号用于**结构对称的排比句群分层**,是合法修辞。《南方周末》新年献词经典结构是连用多个分号分隔排比段落（`...;...;...。`）,这是严肃论述体的标准节奏,**不改**。
> - **判据：** 分号两侧是不是**结构对称的句子**?对称 → 合法排比,保留;不对称 → 英文句法硬拼,改。

## 书名号「《》」：覆盖面比一般人以为的更广

严肃媒体的书名号覆盖范围远超"书"本身:

- **刊物**：《三联生活周刊》《财新周刊》《爱乐》《读书》
- **书籍、电影、音乐作品、MV**
- **政策文件、法规、政府报告**：《中共中央关于制定国民经济和社会发展第十五个五年规划的建议》
- **栏目名、专题名**：《拆新闻》《从现场出发的传播学》
- **年度产品 / 特定作品**：《2025 三联生活历》

**AI 常见误用：** 用引号 `""` 代替书名号（`"人民日报"`）,或直接裸写不加任何标记。真人写作里书名号使用率远高于 AI 输出。**正式语境里书名号反常稀少、被引号代行,是 AI 腔信号。**

## 省略号「……」：严肃正文基线 ≈ 0,比破折号还稀有

观察到的严肃长文样本（《南方周末》新闻稿与新年献词、《财新周刊》封面报道)里,省略号出现次数**全部为 0**。

省略号合法出现的场景:

- **对话 / 口述实录**里的未尽意：`"我也不知道……就这样吧。"`
- **列举未完的"等等"义**：`春天的香椿、夏天的荷花、秋天的月……`
- **文艺 / 散文 / 营销文案的节奏需要**
- **小红书 / 朋友圈 / 微信私聊**等随意语体

**严肃议论 / 新闻 / 财经正文里出现省略号,反而是刺眼信号。**

**格式规范：** `……`（两个 U+2026,占两字宽）,不是 `...`（三个半角点）、不是 `。。。`、不是 `. . .`。

## 冒号「:」vs 破折号「——」：引出信息是冒号的活,不是破折号

严肃媒体里,凡是"引出"动作 —— 引语、列表、署名、副标题、小标题 —— 默认冒号,不是破折号:

- **引语**：`他说:"我不知道。"`
- **署名**：`责任编辑:XXX` / `发自:重庆`
- **小标题**：《财新周刊》`秦泗钊:要学机器不会做的事`
- **列表起首**：`这次改版重点:登录流程、bug 修复、首页布局`

破折号承担的是**补注、强调、转折、节奏**,不是引出。

**AI 常见误用：** 把 `X:Y` 改成 `X——Y`,尤其是引语前。看到"他说——""报告指出——",基本是 AI 腔。跟规则 #16 / #25 互锁。

---

## 引号「""」的三种合法用途

真人用引号的三种合法场景:

1. **直接引语**：`她说:"明天再来。"`
2. **概念 / 术语的标引**（尤其政治、经济、专题术语）：《财新周刊》用 `"十五五"` `"钱袋子"` `"同案不同判"` 标引简称、比喻性表达、专题名
3. **反讽 / 特殊用法**：`这就是所谓的"优化"`

**AI 常见误用：**

- 在每个普通名词上加引号（`"用户"打开"应用"使用"功能"`）
- 用双引号代替书名号（`读"三联生活周刊"`）
- 在非引语场景给动作 / 状态加引号（`他"思考"了一下`）

**嵌套规则：** 外层双引号 `""`,内层单引号 `''`。`他说:"她告诉我'别走'之后就挂了电话。"`

## 括号「()」：次要补注,不引出主干

括号内容是**可删除不影响主干**的次要信息。严肃媒体主要用在:

- **英文缩写补注**：`世界超级摩托车锦标赛(WSBK)`
- **时间 / 地点 / 来源**：`(2026-01-29 发稿,北京)`
- **数据来源、署名**：`(作者名 / 视觉中国)`
- **次要解释**：`这个工具(早期叫 Bard)很好用`

**跟破折号的分工：** 括号 = **次要补注**（读者可跳过）,破折号 = **重要补注 / 强调 / 转折**（读者不能跳过）。AI 常犯的错是**全用破折号**,把次要和重要都压成同一强度。

## 严肃媒体的标点频率基线（校准证据）

基于对《三联生活周刊》《南方周末》《财新周刊》2026 年刊文与公众号推送的观察,严肃中文媒体正文里标点频率基线从高到低大致是:

```
。  ,  、  :  "" ?  !  《》  ——  ;  ……  ( )
```

**越靠右越稀有。** AI 输出里,`——` `;` `( )` 经常反常密集（英文训练数据里这三个都是高频符号）;`《》` 和 `……` 经常反常稀少（被引号和 `...` 替代）。**跟这个基线反向偏离,是重要 AI 腔信号。**
