# Unslop

编辑文本，去除 AI 痕迹，保留人的声音。人性化不等于口语化，也不等于编造观点、细节或经历。

## 流程

1. 确认待改文本；没有文本时直接向用户索要。识别语言、体裁、目标读者和原文语气，信息不足但可安全推断时说明采用的处理方式。
2. 扫描下列模式，区分真正影响阅读的问题与正常用词，不机械替换禁词。
3. 重写并保留原意、事实、条件、引文和不确定性。不得新增来源、数字、用户反馈、个人经历或原文没有的观点。
4. 只有原文本来采用第一人称，或用户明确要求加入其真实声音时，才使用“我”和个人立场；事实型、技术型文本以准确自然为先。
5. 自我审查：“哪一句仍显得模板化？哪一句改变了原意？”修复后交付重写文本；修改说明仅在有帮助时附上。

## 需要检测并修复的模式

### 内容

- **浮夸词**：「关键时刻」「见证」「不断演变的格局」「为……奠定基础」「不可磨灭的印记」「根深蒂固」。删掉浮夸词，直接陈述发生了什么。
- **罗列媒体**：不加背景地列举媒体机构。保留与主题相关的具体报道内容。
- **浅薄的分词短语**：「highlighting…」「ensuring…」「reflecting…」「showcasing…」「fostering…」。删除，或用已有证据说明真实机制。
- **宣传性语言**：「坐落于」「充满活力」「叹为观止」「开创性」「久负盛名」「惊艳」「必游之地」。改用中性描述。
- **模糊归因**：「专家认为」「行业报告表明」「一些评论家认为」。保留真实来源，否则删除归因；不得补造来源。
- **公式化的挑战**：「尽管面临挑战……仍在蓬勃发展」。用原文中的具体事实替换。

### 语言

- **AI 词汇堆叠**：Additionally、crucial、delve、enduring、enhance、fostering、garner、interplay、intricate、landscape（抽象义）、pivotal、showcase、tapestry（抽象义）、testament、underscore、vibrant。仅在空泛或重复时换成平实词。
- **「是」的花哨说法**：「serves as」「stands as」「boasts」「features」。自然使用「是」或「有」。
- **「不只是 X，而是 Y」**：反复出现时直接陈述要点。
- **三点排比**：不要为显得全面凑三组，按实际内容组织。
- **同义词轮换**：同一对象反复改称 protagonist、main character、central figure、hero。保持称谓稳定。
- **虚假范围**：「从 X 到 Y」两端不在同一尺度时，直接列出主题。

### 风格

- **滥用破折号**：多处使用 em dash 制造戏剧性时，按语法改用句号或逗号；不机械删除所有必要标点。
- **滥用冒号**：列表或示例前的冒号可以保留，句中用于强行连接对比时重写。
- **滥用加粗**：不要给每个专有名词或缩写加粗。
- **行内标题列表**：加粗标签加冒号且内容重复时改成自然段落；真正有助于扫读的标签可以保留。
- **标题用 Title Case**：英文标题按目标风格改为 sentence case。
- **装饰性表情符号**：从正式标题和列表项中删除。
- **引号风格**：按原文语言和发布规范统一，不把中文引号强制改成英文直引号。

### 沟通产物

- 删除「希望这能帮到你」「如需……请告诉我」「当然可以」「好问题」等聊天套话和讨好语气。
- 删除模型身份与训练日期等对话元信息；事实本身不确定时仍须保留必要限定。

### 填充

- 「In order to」改成「To」，「Due to the fact that」改成「Because」，「It is important to note that」按语义删除。
- 删除重复的过度含糊，保留必要的概率和不确定性。
- 「未来一片光明」等泛泛结论，优先用原文已有的具体计划或事实替换；没有就删去。

### 行话

Substrate、wedge、vector、locus、vantage、nexus、primitive、harness、surface、bedrock、scaffolding、modality、paradigm、gold-plating、ratchet、endgame、north star、flywheel 等词若只是抽象包装，换成该语境中真实、具体的机制或动作。专业术语本身准确且必要时保留。

### 平实表达

- 说清事物做什么，而不是只写它给人的感觉；无法转成具体事实或指令的修饰语可以删除。
- 长句需要回读时拆成两句，一句一个主要意思。
- 优先主动语态；施动者未知或无关紧要时可保留被动。
- 删除装饰性副词，用准确动词、动作、感官细节或已有数字表达；必要的时间、逻辑、频率和程度副词保留。
- 优先平实词：utilize → use，leverage → use，facilitate → help，numerous → many，in the event that → if。
