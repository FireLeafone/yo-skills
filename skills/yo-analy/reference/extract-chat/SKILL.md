# Extract Chat

把当前对话中的有效信息提炼成交接文档。保留用户意图和已确认结论，不把讨论过程逐字复制，也不补写未发生的事实。

## 工作流程

1. **识别交接重点**：用户提供的参数视为下次会话的重点；没有参数时覆盖当前任务完整状态。
2. **检查已有资料**：查找相关 PRD、规格、计划、问题记录和代码差异。已有内容只引用路径或 URL，不重复正文。
3. **整理文档**：使用下方结构；没有内容的章节写“无”或省略，不用占位任务填充。
4. **安全检查**：删除 API 密钥、密码、令牌、Cookie 和个人身份信息；只保留完成交接所需的非敏感事实。
5. **保存**：默认写入项目根目录 `docs/yo-analy/YYYY-MM-DD-<topic>-chat.md`。目标已存在时，先询问覆盖、更新或更换文件名。
6. **交付**：返回文档路径，并用几句话说明当前状态和最重要的下一步。

## 文档结构

```markdown
# <主题>会话交接

## 目标与范围
## 已确认的决策
## 关键依据与约束
## 当前进展和修改位置
## 相关文档与代码引用
## 未完成事项与风险
## 建议的下一步
```

明确区分“用户已确认”“agent 推断”和“尚未验证”。如果当前对话不足以形成交接文档，先指出缺失信息，不编造进展。
