# 极简讲解图

用「完全不懂这个主题的人」能看懂的方式，把概念讲成一张张极简图。适用于概念、原理、算法等**非系统架构类**主题（系统/架构类请改用 `diagram.md`）。

## 设计原则

- **一张图只讲一个点**：不要在一张图里塞多个概念。
- **少文字**：框内最多 2-5 个词；一句话讲不清就用图。
- **大字号、多留白**：宁可空，不可挤。
- **先讲「是什么」，再讲「怎么工作」，最后讲「为什么重要」**。
- **善用类比**：把陌生概念映射到日常事物（如「区块链 = 大家共用的记账本」）。

## 配色

使用明亮、友好、低饱和的配色，避免技术感过重：

| 用途 | 填充色 | 描边色 |
|------|--------|--------|
| 主概念 | `#e0f2fe` | `#0284c7`（天蓝） |
| 次要概念 | `#fef3c7` | `#d97706`（琥珀） |
| 过程/步骤 | `#dcfce7` | `#16a34a`（绿） |
| 类比/提示 | `#fce7f3` | `#db2777`（粉） |
| 中性元素 | `#f1f5f9` | `#64748b`（灰） |

## 视觉元素

- **方框**：圆角矩形（`rx="12"`），浅色填充 + 1.5px 描边，内文居中。
- **箭头**：粗箭头（`stroke-width="2"`），用 SVG marker 画箭头头部，颜色随方框。
- **分组**：虚线圆角框（`stroke-dasharray="6,4"`）表示「这几个是一伙的」。
- **步骤**：用带数字的圆点或卡片表示顺序。

## 布局结构

1. **标题**：大标题 + 一句话概括（这玩意是干嘛的）。
2. **核心概念图**：一张大 SVG，把「是什么」画出来。
3. **分步卡片**：2-4 张卡片，讲「怎么工作」。
4. **类比框**：一句话类比，帮人记住。
5. **小结**：一句话 takeaways。

## 组件方框模板

```svg
<rect x="X" y="Y" width="W" height="H" rx="12" fill="#e0f2fe" stroke="#0284c7" stroke-width="1.5"/>
<text x="CENTER_X" y="CENTER_Y" fill="#0f172a" font-size="16" font-weight="600" text-anchor="middle">概念名</text>
```

## 分步卡片模板

```html
<div class="step-card">
  <div class="step-num">1</div>
  <h3>这一步做什么</h3>
  <p>一句话说明。</p>
</div>
```

## 模板

复制 `resources/simple-template.html` 并按需定制：改标题与概览、替换核心概念 SVG、增减分步卡片、填类比与小结。

## 输出

始终产出一个自包含的 `.html` 文件：内嵌 CSS 与 SVG，不依赖外部资源（不引 CDN），浏览器直接打开即可。
