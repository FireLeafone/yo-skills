用「完全不懂这个主题的人」的视角，把主题讲成一份**自包含 HTML 文档**：多图、少字、重点突出、可直观理解。

## 工作流

1. **确认主题**：拿到要解释的主题。若用户没给主题（或主题含糊），先问一句再动手，不要瞎猜。
2. **判断类型并选参考**：
   - **概念/原理/算法类**（如「区块链是什么」「TCP 三次握手」）→ 读 `references/simple-diagram.md`，用 `resources/simple-template.html` 模板。
   - **系统/架构/数据流类**（如「这个系统的整体架构」）→ 读 `references/diagram.md`，用 `resources/template.html` 模板。
3. **生成文档**：产出单个自包含 HTML（内嵌 CSS/SVG，浏览器直接打开即可渲染）。
4. **交付**：保存为 `/docs/yo-analy/<主题slug>.html`（默认项目根目录，或用户指定路径），并回显文件路径。

## 应该做 / 禁止做

- **应该做**：少文字、多图，用类比/分层/分步讲清「是什么 → 怎么工作 → 为什么」；即使画架构图也保持外行能看懂。
- **禁止做**：堆术语、贴大段代码、写成教科书。
