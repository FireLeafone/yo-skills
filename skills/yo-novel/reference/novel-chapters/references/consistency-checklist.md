# 章节规划一致性检查清单

供 `novel-chapters` 在两处使用：

- **A. 每卷自检**：每生成一卷后、生成下一卷前执行（SKILL.md Step 3.5）。
- **B. 全书终检**：总览文档生成后执行一次（SKILL.md Step 5）。

只核对"章节规划"与 `presets/` 设定的一致性，不检查正文；正文自检由 `novel-write` 的 `checked.md` 流程负责。

## 使用方式

1. 对照清单逐项核对，禁止凭印象批量勾选。
2. 项目缺少对应设定文件（如无 `presets/world.md`）时，相关项标记**未核对**并写入汇报，禁止假设通过。
3. 机械错误（笔误、编号、链接、空占位）直接修复并在汇报中列出；修复后复核受影响的关联项——改了章节数就重查编号连续与总览合计。
4. 需要改动已确认的规划方案或大纲的问题：🛑 STOP — 列出问题与至少两种处理选项，等待用户取舍，不得擅自改方案。
5. 复查模式下若 `chapters/index.md` 不存在，B 部分中依赖总览的项直接基于各卷 `index.md` 核对，并在汇报中提醒可补生成总览。
6. 复查既有规划若未标注章节类型/强度（旧格式），A7、B6 中的相关项按**未核对**处理，并在汇报中说明可补标后复核。

## A. 每卷自检

### A1. 章节编号与数量

- [ ] 各阶段章节区间连续、无重叠、无断档
- [ ] 各阶段章节数之和 = 本卷声明的总章数
- [ ] 本卷首章号承接上一卷末章（第一卷从全书第 1 章起）
- [ ] 章节表内的章节号与阶段标题中的区间一致

### A2. 大纲节点覆盖

- [ ] 本卷应覆盖的 `presets/outline.md` 情节节点均已安排到具体章节（不漏）
- [ ] 同一大纲节点没有被安排进多章重复推进（不重）
- [ ] 大纲外新增情节已标注"新增"并待用户确认（或已包含在确认方案中）

### A3. 人物一致性

- [ ] 出场人物表中的角色均存在于 `presets/characters.md`，名字/称呼写法一致，未凭空造人
- [ ] 新角色已在表中列出并标注为新增设定
- [ ] POV 角色真实存在；限知视角下不能进入他人内心
- [ ] 人物状态（登场/成长/转折/退场）与人物弧线设定一致
- [ ] 已退场角色未再出现在后续章节的"主要人物"列（回忆/闪回除外，且应可辨识）

### A4. 设定一致性

- [ ] 场景地名、势力、组织、术语与 `presets/world.md` 一致，无设定外地名
- [ ] 涉及能力/等级/职位的情节未超出 `characters.md` / `world.md` 设定的上限
- [ ] 经济、物价、距离、交通耗时等硬数字符合 `presets/settings.md` 且可自洽

### A5. 时间线

- [ ] 卷 header 已填写时间跨度（无纪年体系可用相对表述）
- [ ] 时间跨度与上一卷衔接，承接处无时间空洞或重叠
- [ ] 卷内事件时序因果合理，无"结果先于原因"
- [ ] 无同一人物同时出现在两地、信息未传递却已知晓等穿帮
- [ ] 关键时间点（约期、大战、期限）在卷内前后一致

### A6. 伏笔

- [ ] 卷内引用的每条伏笔均已在 `presets/foreshadowing.md` 登记，编号一致
- [ ] 埋设章、计划回收章均落在本书已规划的章节范围内
- [ ] 无"收了没埋"：回收章之前存在埋设或推进章
- [ ] 卷文档中的伏笔列仅为计划视图，未另维护状态列

### A7. 情节配比与节奏

- [ ] 每章已标注类型（对抗/推进/日常/情感/揭示）与强度（💤🟢🟡🟠🔴⚫），无空缺
- [ ] 本卷各类型实际占比与确认的配比方案一致；偏差超过 ±10 个百分点已在"情节配比与节奏核对"中写明原因
- [ ] 对抗类章节数不为零（除非配比方案明确免除）；对抗子标签未连续重复 3 章以上
- [ ] 同一主类型连续不超过 5 章；🟠 及以上强度连续不超过 3 章（阶段"节奏设计"中注明的多章决战段除外）
- [ ] 小高潮（🔴）约每 8–15 章出现一次；🔴/⚫ 之后存在 💤/🟢 回落章，高潮未被连续堆叠
- [ ] 无流水线段落：无 3 章以上"主要内容"句式雷同循环，每章写明带来的具体变化（关系/认知/处境/实力/信息至少一项）
- [ ] 每章"主要内容"言之有物，无"继续推进剧情"式空泛占位
- [ ] 章尾钩子存在，且未连续多章重复同一手法

### A8. 前后卷衔接

- [ ] "承接上卷"栏内容与上一卷"铺垫下卷"栏真实对应
- [ ] 本卷第 1 章承接上卷结尾，而非另起炉灶（第一卷改为：对应大纲的开端事件）

## B. 全书终检

### B1. 结构完整

- [ ] 各卷章节数之和 = 总览声明的总章节数
- [ ] 章节编号全局连续：卷 N 末章 + 1 = 卷 N+1 首章
- [ ] 总览中每卷的章节范围、章节数、时间跨度、主题与各卷 `index.md` 一致
- [ ] 总览中所有分卷链接路径有效（`./volume-NN/index.md`）

### B2. 大纲全覆盖

- [ ] `presets/outline.md` 的全部情节节点都能定位到具体卷、章
- [ ] 全书首尾对应大纲的开端与结局节点，无结局缺失

### B3. 人物弧线闭环

- [ ] 主要人物均有始有终：登场卷与退场/收束卷可追溯
- [ ] 跨卷人物状态变化连续；前卷退场、后卷再入有交代
- [ ] 无主要人物整卷"消失"（刻意雪藏的已标注说明）

### B4. 跨卷时间线

- [ ] 各卷时间跨度按卷序首尾相接（重叠或倒叙须有明确理由标注）
- [ ] 全书时间总跨度未超出世界观允许的范围

### B5. 伏笔闭环

- [ ] 对照 `presets/foreshadowing.md`：无"埋了忘收"（登记在册但规划中无回收章）
- [ ] 无"收了没埋"：每条回收都能找到埋设章
- [ ] 跨卷长线伏笔在中间卷至少有一个推进节点
- [ ] 总览"伏笔计划总览"与 `foreshadowing.md` 的编号、埋设/回收位置一致

### B6. 配比与节奏分布

- [ ] 各卷配比与 Step 2 确认的全书方案一致；高潮卷上浮、铺垫卷下浮均有理由标注
- [ ] 全书合计配比与总览"全书情节配比"一致，且与确认方案偏差不超过 ±10 个百分点
- [ ] 全书节奏曲线与各卷阶段划分不冲突：高潮卷内有铺垫，低谷卷内有推进
- [ ] 高潮卷的位置符合大纲的故事阶段定位
- [ ] 全书类型分布无畸形：日常/情感未全书缺席，对抗未全书断档

## 处理策略

| 问题类型 | 处理方式 |
|----------|----------|
| 笔误、编号、链接、空占位 | 直接修复，汇报中列出 |
| 与设定冲突（人物/场景/时间/伏笔） | 🛑 STOP：列出冲突与处理选项，等用户取舍 |
| 大纲节点漏覆盖或重复 | 🛑 STOP：方案级变更，需用户确认 |
| 缺少对应设定文件 | 标"未核对"，汇报中提醒补充设定或确认跳过 |

## 汇报格式

检查完成后，在 Step 6 的结果汇报中附带如下简表（无内容的类别可省略）：

```markdown
## 一致性检查结果

- **通过**：A1–A5、A7
- **已修复**：卷三阶段区间重叠（第 87–90 章重复），已改为 88–91 并同步总览
- **遗留（需用户决策）**：伏笔 F07 无回收章——a) 卷五增补回收章 b) 标记作废
- **未核对**：A4（项目无 `presets/world.md`）
```
