# 写作技巧例证与仿写示例

本文件用于把“这本书写得有什么特点”进一步转化为“下游 agent 可以怎样照着做”。在 `SKILL.md` 第 4 步发现代表性技巧时阅读本文件，并将结果填入输出模板的对应场景配方或附录 B 技巧库。

## 选取原则

- **特色优先**：选择重复出现、效果鲜明、能体现本书辨识度的技巧。例文充分时通常选 4–8 个，不足时按实际数量，不为覆盖类别而凑数。
- **证据先行**：原作片段只能逐字取自用户提供的例文，并注明段落编号。外部评论可帮助判断技巧是否属于全书特征，但不能作为原著引文。
- **完整示范**：一张技巧卡要同时回答“原作怎么写、为什么有效、换了情境怎么写、何时不要用”。
- **学机制而非搬内容**：生成示例更换人物、情境和具体措辞，只保留可复用的写作机制。
- **证据不足不硬补**：只有评论、没有例文时，可以给出低置信度的技巧判断和生成示例，但“原作片段”必须写“未提供例文”；连可靠评论也没有时不收录该技巧。

## 技巧例证卡格式（Agent 版）

```markdown
### <技巧名：写的时候用在哪>
- 适用场景：<适合承担的叙事任务或情绪节点>
- 原作片段：“<用户例文中的真实片段>” —— 用户例文第 <X> 段
- 机制：<拆分结构、措辞、视角或调度方式，并解释阅读效果>
- 写的时候怎么做：<步骤、句式或结构模板，让使用者能据此操作>
- 正例（生成，非原文，150–300 字）：<用新人物、新情境写一段能直接当范文的段落>
- 反例：<常见跑偏写法，100 字以内，让差异可见>
- 自检：<写作时能直接回答的一个问题>
- 使用边界：<不适用的情况和过度使用的风险>
- 置信度：<高/中/低，并说明证据强弱>
```

“机制”和“写的时候怎么做”不能只是换一种说法重复“可仿写要点”：前者解释原作片段为何有效，后者把机制改写成新情境中可执行的步骤。正例必须是一段完整的、能直接当范文的文字，不能只写一句金句；反例要写出仿写者最可能犯的错。

## 场景配方卡格式

```markdown
### <场景类型：如制度压迫/征收、官场对话、战斗/守城>
- 目标：<这类场景完成什么叙事任务>
- 节拍：
  1. <开场：文书/动作/对话/物象>
  2. <中段：谁出场、每人的账、冲突怎么升级>
  3. <转折：什么信息/事件改变了局面>
  4. <收束：一个后果/画面/钩子>
- 视角：<贴谁；谁不能知道什么；什么时候切>
- 语言：<句长、行话、数字、暴力/情感的处理>
- 正例（生成，非原文，150–300 字）：<能直接当范文的段落>
- 反例：<常见跑偏写法，100 字以内>
- 自检：<写作时能直接回答的一个问题>
```

## 人物声纹卡格式

```markdown
### <人物>
- 功能：<镜子/对手/导师/催化剂/执行层>
- 自称/称呼：<对上官、对下属、对平辈分别怎么自称/称呼>
- 句长/语气：<短促/绵长、软/硬、急/缓>
- 口癖/用词：<固定词、行话、粗口、方言、官话>
- 示例台词（生成，非原文）：“<1–3 句，只模仿声纹，不抄原文>”
- 不要写成：<最容易写成的扁平形象>
```

## 各类技巧怎么举例

以下类别是观察清单，不是必须填满的目录。只收录有证据且有作品辨识度的技巧。

### 对话

- 观察人物腔调、句长、措辞、答非所问、沉默、打断、潜台词，以及对话之间的动作节拍。
- 原作片段应保留足够的连续回合，让辨识度或潜台词真正可见，不能只摘一句脱离语境的“金句”。
- 机制要说明“这句话表面上在说什么、实际在推进什么关系或冲突”。
- 正例（生成，非原文）通常写 2–4 个回合，沿用相同的潜台词或节奏机制，但更换人物关系和话题；反例写出“所有人一个腔调/直白说明”的常见跑偏。

### 人物描写

- 观察外貌细节、习惯性动作、关键选择、心理矛盾、语言特征和他人反应如何互相印证。
- 优先选择“细节让读者自行判断人物”的片段，区分直接评价与间接塑造。
- 机制要指出细节与性格之间的推导关系，而不是把“敏锐、坚毅、复杂”等标签再写一遍。
- 正例（生成，非原文）通过同类塑造手段呈现一个新人物，不照搬原作人物的外貌标志、口癖或经历；反例写出“直接贴标签/外貌清单”的常见跑偏。

### 场景转换与转场

- 观察场景、时间、地点、视角和情绪段落的切换；留意硬切、时间锚点、动作承接、感官桥梁、共同意象等方式是否在原作中真实出现。
- 原作片段必须包含切换前的收束与切换后的起笔，必要时保留两个相邻段落。
- 机制要说明转场保留了什么连续性，又改变了什么信息；不要把所有转场都笼统归为“自然流畅”。
- 正例（生成，非原文）同时写出旧场景的结尾和新场景的开头，让衔接方法可直接比较；反例写出“与此同时/话分两头”的过渡总结。

### 叙事视角与语言

- 观察叙述距离、限知边界、自由间接引语、句内停顿、长短句组织、喻体来源和感官细节。
- 选能体现视角或语言机制的短片段，不用孤立词语证明整体文风。
- 正例（生成，非原文）保持相同的信息边界或句法机制，但更换观察对象与意象内容；反例写出“视角越界/全知剧透”的常见跑偏。

### 节奏与信息释放

- 观察场景压缩、详略切换、章末钩子、延迟说明、插叙、读者与人物的信息差。
- 说明技巧作用于“事件何时发生”还是“读者何时知道”，不要混为一谈。
- 若单个片段不足以证明跨章节规律，只用外部评论作低置信度补充，不虚构全书比例或位置。
- 正例（生成，非原文）展示同一段新情节在相应节奏或信息调度下如何展开；反例写出“信息一次讲完/节奏靠短句硬凑”的常见跑偏。

### 冲突、伏笔与环境描写

- 冲突示例要呈现人物目标与阻力，不只写“矛盾激烈”。
- 伏笔示例要指出首次出现时的表面功能和后来的潜在意义；没有回收证据时不得断言它是伏笔。
- 环境与感官描写示例要说明环境怎样影响人物感受、选择或冲突，而不是只罗列景物。

## 正例/反例检查

- [ ] 正例明确标注“生成，非原文”，不会与原作片段混淆。
- [ ] 正例使用新人物、新情境和新措辞，没有复制原作专有名词、标志口癖或完整句子。
- [ ] 正例确实演示了技巧卡所说的机制，而不是只写得“好看”。
- [ ] 正例长度足以看清技巧：对话有必要回合，转场有切换前后，人物描写有可推导性格的细节。
- [ ] 反例写的是仿写者最可能犯的错，而不是随便写一段更差的文字。
- [ ] 技巧卡来自本作证据，不是可以套进任何小说的通用写作建议。
- [ ] 使用边界说明何时该克制，避免下游 agent 把技巧无限放大。
