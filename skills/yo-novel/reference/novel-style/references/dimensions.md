# 维度提取细则

本文件是 `SKILL.md` 第 4 步"多维度提取"的展开。每个维度给出：**看什么**（在例文与评论里找什么证据）、**怎么落**（把结论写成可仿写要点而非形容词）、**常见陷阱**。

## Agent 化落法（本文件的核心）

每个维度不要只写“特征描述”，必须产出四件事：

1. **写的时候怎么做**：2–5 条祈使句，能直接指导下一段。
2. **不要怎么做**：2–3 条常见跑偏。
3. **自检问题**：1–2 个写作时能回答的问题。
4. **证据/置信度**：一句话说明证据强弱，放到附录。

检验标准：把这条交给一个没读过原著的写作 agent，它能否据此判断“我这一段写得像不像、该不该这样写”。通不过就继续往下拆，不要留形容词。

## 核心维度（默认全量提取）

### 1. 叙事视角

- **看什么**：人称（一/二/三）、限知还是全知、是否多视角切换、切换的触发条件、叙述者与人物的心理贴近度（贴着人物内心走，还是保持外科医生式的距离）、是否打破第四面墙/元叙事。
- **怎么落**：写清"第几人称+限知/全知+视角切换规则"。例如"三人称限知，主贴主角 A 视角；每章末尾切换到反派 B 视角制造信息差"。
- **常见陷阱**：把"全知"和"上帝视角随意剧透"混为一谈——全知 narration 也可以选择性地不给信息。要区分"能力上是全知"与"实际操作上是否克制"。

### 2. 主角性格特征

- **看什么**：性格内核（一两句话能说清的"人物引擎"）、行为逻辑（遇到冲突的本能反应）、内在矛盾/渴望与恐惧、成长弧线的方向与幅度、是否有不可靠自我认知。
- **怎么落**：给出"人物引擎"式的一句话（"X 是一个在 A 渴望与 B 恐惧之间反复横跳的人"），并指出驱动其决策的底层动机。可仿写要点应能让仿写者判断"这个情境下主角会怎么选"。
- **常见陷阱**：堆砌形容词（"坚毅、善良、聪明"）而无行为锚点。性格要落到"他在 X 情境下会做 Y"才可仿写。

### 3. 主要配角性格特征

- **看什么**：每个重点配角在故事里的功能定位（镜子/对手/催化剂/导师）、性格辨识度（语言/行为是否有独立指纹）、与主角的对照或镜像关系、是否服务于主题。
- **怎么落**：**按配角逐人拆成独立小节**，不要把所有配角塞进一段。先挑出"跨卷长线 / 高辨识度"的若干个（通常 3-6 个，视作品而定），每个配角一条，点明"功能定位 + 辨识指纹 + 与主角的关系 + 可仿写要点"。如果原作配角整体单薄（凡人流、长篇连载常见），先说一句结构层面的短板，再逐人拆，并明确把"配角单薄"列为仿写时的**主动改进项**而非照搬项。可仿写要点落到"该角色的对话腔调/决策倾向/与主角的对照关系"层面。
- **常见陷阱**：把配角写成纯功能性工具人——若原著配角有独立生命，仿写时也别让配角沦为传声筒。另一个陷阱是只评"配角群像单薄"而不逐人点名，导致仿写者无从下手——**必须落到具体的人**。

### 4. 全书风格气质

- **看什么**：整体基调（冷峻/温情/戏谑/苍凉/癫狂……）、审美气质、情绪底色、作者对世界的态度（悲悯/嘲讽/冷眼/热爱）。这一维度最依赖网评交叉验证，单凭例文可能只见树木。
- **怎么落**：给一个锚点式概括 + 两三个可操作的气质参数（"克制冷感：情感高点也用陈述句而非感叹句；距离感：叙述者很少替人物抒情"）。
- **常见陷阱**：用一个形容词打包全书（"这本书很深沉"）——气质是多参数的，要拆。

### 5. 小说推进节奏

- **看什么**：章节平均字数与场景密度、张弛分布（密集冲突段与缓冲段的比例）、时间跨度处理（实时/压缩/跳年）、信息密度分布（前重后轻？匀速？）、是否有"钩子"结构（章末悬念）。
- **怎么落**：给可量化或可对照的节奏参数，如"场景平均 800–1200 字切换、章末必有悬念钩子、大冲突后接 1 段日常缓冲"。
- **常见陷阱**：把"节奏快"当成优点笼统赞美——要分清是"事件密度高"还是"句子短"，两者仿写方式完全不同。

### 6. 语言文字质感

- **看什么**：句式（长短句比例、复句嵌套）、用词 register（书面/口语/术语/古语/方言占比）、修辞偏好与喻体来源域、感官描写比重、音韵节奏（是否讲究句内停顿、押韵感）、段落呼吸感。
- **怎么落**：落到可执行的参数，如"短句占比约 40%、善用比喻且喻体多取自科技域、少用成语、对话不加'他说'以外的提示语"。
- **常见陷阱**：这是最容易被"形容词化"的维度。"语言优美"不可仿写，"用 3–7 字短句叠加、喻体取自物理/天文"才可仿写。务必逼自己落到参数。

### 7. 冲突和伏笔设计

- **看什么**：冲突层级（人物内心/人际/人与社会/人与自然/理念之争）、冲突驱动方式、伏笔铺设密度与回收方式（明伏笔/暗伏笔、近回收/远回收）、悬念结构（是否多线悬念并行）。
- **怎么落**：点明主导冲突层级 + 伏笔的典型手法（如"重要道具在前 1/3 出现时不点破用途，于 2/3 处自然回收"）。
- **常见陷阱**：把伏笔等同于"反转"。伏笔的核心是"埋的时候看似无用"，要区分伏笔、铺垫、反转。

### 8. 世界社会整体环境温度

- **看什么**：世界观设定粒度、社会氛围（压抑/松弛/动荡/原子化）、时代温度（什么历史阶段、技术水准、意识形态底色）、环境对人物是压迫还是滋养、环境本身的"质感"（肮脏/洁净/荒凉/喧嚣）。
- **怎么落**：给"环境—人物"的关系参数（如"环境以钝刀方式持续施压，人物决策多是对环境的妥协而非反抗"）。
- **常见陷阱**：只描述设定不写"温度"。设定是冷的清单，温度是读者感受到的体感——仿写要的是体感。

### 9. 信息释放方式

- **看什么**：何时给信息、给多少、通过谁给（叙述者直给/人物对话/行动展示/文件嵌入）、留白与揭秘的节奏、是否有不可靠叙述（叙述者刻意藏/骗）、读者与人物的信息差（读者比人物多知道多少）。
- **怎么落**：给出信息释放的"调度规则"，如"关键真相通过配角闲谈侧面透露、主角比读者晚一章知晓、结尾不收全部线"。
- **常见陷阱**：把"信息释放"和"节奏"混为一谈。节奏是"事件何时发生"，信息释放是"读者何时知道"——同一事件可以早说（铺垫）或晚说（悬念）。

### 10. 对话风格特点

- **看什么**：对话在全书的功能（推进情节/塑造人物/释放信息/制造潜台词）、人物语言辨识度（遮住名字能否认出是谁在说）、潜台词比重、对话与动作描写的配比、提示语习惯。
- **怎么落**：给出对话的"指纹参数"，如"对话占篇幅约 35%、人物腔调高度分化、潜台词多于直白、提示语多用动作而非'他说'"。
- **常见陷阱**：只评"对话精彩"。要落到辨识度——给两个角色各一句典型台词的"腔调模板"（不是抄原句，而是描述其说话方式）。

## 维度 → 写作动作速查

| 维度 | 写的时候怎么做 | 不要怎么做 | 自检问题 |
| --- | --- | --- | --- |
| 叙事视角 | 默认贴主角；内心用主角的语言；换场景用“……”+地点+物象；换视角只在地点/时间/阵营变化时 | 场景中途换头；用“与此同时”过渡；全知剧透 | 这段的视角人物知道这件事吗？ |
| 主角 | 每场景先算账；善意小额、具体、有代价；胜利靠算计/组织/信息 | 道德觉醒；见一个帮一个；料事如神 | 他付出的成本是什么？ |
| 配角 | 给每个常设角色“自称+口癖+句长”三件套和一条利益动机 | 所有配角一个腔调；反派为恶而恶；配角只传话 | 遮住名字能认出谁在说吗？ |
| 气质 | 情感高点用陈述句和动作；残酷配冷幽默；悲悯用物件 | 感叹句抒情；苦情戏；血浆片 | 这段有没有作者替人物哭？ |
| 节奏 | 一章 2–4 个场景；每场景结束有可量化变化；章末停在画面/问题/打脸句 | 用短句冒充快节奏；过渡总结；场景无变化 | 这个场景结束时什么变了？ |
| 语言 | 叙述 10–30 字为主；现代术语只进叙述/内心；每 1–2 章一处文献级细节 | 现代词进对话；连续三句纯设定；形容词堆砌 | 这段有没有连续三句纯设定？ |
| 冲突/伏笔 | 先问利益结构；伏笔伪装成温情/滑稽/技术妥协；回收只给画面/后果 | 伏笔埋得太明显；回收点破；冲突靠坏人性格 | 这个冲突是制度/利益，还是坏人？ |
| 环境 | 把宏观危机折算成价格/利息/税额/兵力；写流程不写惨状 | 开头宣讲小冰河/白银；环境只做背景板 | 删掉环境句，人物决策还成立吗？ |
| 信息释放 | 三拍：对话给出→主角翻译→据此决策；双方各一份不完整情报 | 叙述者一次讲完；全知剧透；设定说明书 | 读者现在知道什么、人物知道什么？ |
| 对话 | 每个角色三件套；官场写两本账；用短问/沉默/打断 | 所有人一个腔调；提示语全是“他说”；对话变说明文 | 遮住名字能认出谁在说吗？ |

## 可选补充维度

当原作有明显特色时补做，否则可略：

- **情感基调与主题取向**：核心母题、情感落点、作者的价值判断。
- **意象 / 象征系统**：反复出现的意象及其象征荷载、是否构成隐喻网络。
- **叙述者与读者距离感**：是否打破第四面墙、有无元叙事、对读者的态度（谄媚/挑衅/平视）。
- **人物描写手法**：外貌、动作、心理、语言及他人反应如何互相印证；细节是直接说明性格，还是让读者自行判断。
- **场景转换与转场**：场景、时间、视角及情绪段落如何切换；使用硬切、时间锚点、动作承接、感官或意象桥梁中的哪种方式，切换前后各保留什么信息。
- **章节结构习惯**：是否多线交织、章节切分逻辑、卷/部划分的节奏意义。
- **时间叙事**：线性/倒叙/插叙/多时间线并行、时间标记习惯。

## 场景配方观察清单

当例文或外部资料能支撑时，至少为 4–6 类高频场景写配方；证据不足时按实际能支撑的类型输出，并标注缺口，不为凑数虚构。每类观察：

- **目标**：这类场景在故事里完成什么（压迫/结盟/揭示/转折/喘息）。
- **节拍**：开场用什么（文书/动作/对话/物象）；中段按什么顺序推进；结尾停在哪。
- **视角**：贴谁；谁不能知道什么；什么时候切。
- **语言**：句长、行话、数字、暴力/情感的处理。
- **正例/反例**：各写一段（生成，非原文），让差异可见。
- **自检**：一个写作时能回答的问题。

常见场景类型：制度压迫/征收、官场对话/权力、市井对话/信息释放、战斗/守城、场景转换/章节开头、章末钩子/情感落点。

## 人物声纹观察清单

为主要角色建立声纹表，每人观察：

- **自称/称呼**：对上官、对下属、对平辈分别怎么自称/称呼。
- **句长/语气**：短促/绵长、软/硬、急/缓。
- **口癖/用词**：固定词、行话、粗口、方言、官话。
- **情绪表达**：生气/害怕/高兴时声纹怎么变，什么不变。
- **示例台词**：新写 1–3 句，只模仿声纹，不抄原文。
- **不要写成**：最容易写成的扁平形象（如“纯恶人”“纯好人”“传声筒”）。

## 技巧例证衔接

任何维度发现具有辨识度的具体写法，都要判断它是否值得进入最终文档的对应场景配方或附录 B 技巧库。值得收录的信号包括：重复出现、对阅读体验影响明显、区别于通用写作常识、能被转化为明确操作。

- 对话不要只写“生动、有潜台词”，要保留足以看出人物腔调、话外之意或动作节拍的连续片段。
- 人物描写不要只写“形象鲜明”，要指出外貌细节、动作选择、心理矛盾或他人反应怎样共同完成塑造。
- 转场不要只写“切换自然”，要同时分析切换前的收束句与切换后的起笔句，说明两者靠什么衔接。
- 其他技巧也要从具体证据归纳机制，再写成可复用方法，不把评论中的赞美直接当作写作规则。

例证卡的完整格式、各类技巧的观察点和生成示例规则见 `technique-examples.md`。维度小节只保留结论并指向对应技巧卡，不重复粘贴大段示例。

## 证据落法小结

无论哪个维度，"可仿写要点"都要通过这条硬检验：**把这条要点交给一个没读过原著的写手，他能否据此判断"我这一段写得像不像"**。通不过就说明还停留在形容词层，继续往下拆。若技巧本身值得学习，还要用原作片段和生成示例证明它如何落地。
