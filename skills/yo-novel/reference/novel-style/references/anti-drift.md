# 防跑偏框架

仿写一份风格指南时，"写过头"比"写不像"更常见也更危险。本文件给出一套通用跑偏框架，再用它推导**针对某本书**的专属防跑偏清单。

## 通用跑偏框架

下面是仿写任何小说风格时都容易踩的高频坑。提取某本书的风格时，对照这份框架，挑出**该书特别容易中招**的几条，写成专属清单。

### A. 设定堆砌型

- 典型：科幻/奇幻/历史设定浓的作品，仿写时把设定当科普讲，连页技术原理，角色沦为讲解员。
- 根因：把"设定丰富"误当成"多讲设定"。
- 通用自检：连续超过 3 句纯设定（无人物情绪/动作承载）即危险。

### B. 风格过度模仿型（皮相模仿）

- 典型：堆砌原著金句句式、滥用原著的修辞癖好（每段都来个天文比喻），以致矫情、油腻。
- 根因：学的是"形"不是"神"——抄了喻体来源却没学克制。
- 通用自检：同一种修辞手法在单段出现 ≥2 次即过量。

### C. 节奏失真型

- 典型：原著慢的地方仿写也慢，但慢在了不该慢的过渡；或原著快是事件密度高，仿写却只把句子写短。
- 根因：没分清"事件密度快"和"句式短快"。
- 通用自检：抽掉这一段，情节是否仍推进——若不推进且无情绪功能，就是失真慢。

### D. 视角越界型

- 典型：原著限知，仿写时写成全知、提前把另一视角人物的心理抖出来。
- 根因：限知的克制感没学到，只学了人称。
- 通用自检：本视角人物此刻"不该知道"的信息，是否被叙述者剧透。

### E. 信息释放错位型

- 典型：该留的悬念提前给、该给的背景死活不给、或用叙述者强行直给本该由场景揭示的真相。
- 根因：没掌握原著"何时让读者知道"的调度。
- 通用自检：把关键真相出现的位置与原著对照，是否提前或滞后。

### F. 对话失真型

- 典型：所有角色同一腔调，或把原著某人物的标志性口癖安到所有角色身上。
- 根因：只学了"原著对话有辨识度"，没学到"各自不同的辨识度"。
- 通用自检：遮住说话人名字，能否区分是谁在说。

### G. 情绪基调漂移型

- 典型：原著冷峻克制，仿写到动情处忍不住煽情；或原著温暖，仿写时硬学冷感而变得冷漠。
- 根因：用自己习惯的情感表达替换了原著的情感温度。
- 通用自检：本段的情感句式是否符合原著的"情感参数"（如高点也用陈述句）。

### H. 主题窄化型

- 典型：原著主题多维（如命运与自由意志交织），仿写窄化成单一爽点或单一说教。
- 根因：只抓了最显眼的母题。
- 通用自检：本段是否只剩一个主题功能，丢掉了原著的张力。

### I. 人物扁平化型

- 典型：配角纯功能化、主角开挂无内在矛盾。
- 根因：只学了主角"强"没学主角"矛盾"。
- 通用自检：主角此刻是否同时被两个方向拉扯。

### J. 世界观温度失真型

- 典型：只列设定清单，丢掉环境的体感（肮脏/压抑/喧嚣）。
- 根因：把"世界"当背景板而非持续施压者。
- 通用自检：删掉所有环境句后，人物决策是否失去合理性依据。

## 如何推导本书专属清单

1. 复盘第 4 步提取出的各维度特征，问自己："仿写者照着这些可仿写要点写，最容易在哪个维度上**过度**？"
2. 对照上面 A–J，挑出与该书气质最相关的 3–5 类跑偏。
3. 对每类，结合该书具体特征，写成"跑偏点 → 典型表现 → 防范做法"三段式。
4. 再补 1–3 条该书**独有**、框架里没有的跑偏（例如仿写某推理作家的"公平线索呈现"、仿写某意识流作家的"内心独白不塌成流水账"）。
5. 总数 6–10 条，宁少而准，不要凑数。

## 清单条目格式（统一）

```markdown
- 【跑偏点】<一句话点名风险，尽量具象>
  - 典型表现：<具体怎么就跑偏了，举一个仿写情境>
  - 防范做法：<可执行的约束或一个自检问题>
```

好例子（针对硬科幻）：

```markdown
- 【跑偏点】把设定当科普，人物沦为设定工具人
  - 典型表现：连续两页讲曲率引擎原理，角色只是站在原地提问。
  - 防范做法：任何设定披露必须挂在一个有情绪诉求的角色动作上；超过 3 句纯设定就停下来问"谁在着急、为什么着急"。
```

坏例子（太通用，不针对具体书）：

```markdown
- 【跑偏点】注意不要流水账
  - 典型表现：平铺直叙。
  - 防范做法：多加描写。
```

后者放之四海皆准，对仿写**这本书**没有增量信息，不要写进清单。
