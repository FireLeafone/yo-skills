# 配角功能模型详解

## 配角功能标签（40+）

1、战斗型配角

- 忠诚护卫：誓死追随、战斗担当、牺牲高光
- 亦敌亦友：实力相当、互相促进、关键时刻联手
- 师父/前辈：传授功法、指点迷路、壮烈牺牲

2、智囊型配角

- 军师谋士：出谋划策、情报分析、布局推演
- 百事通：消息灵通、人脉广泛、提供线索
- 技术专家：炼丹/炼器/阵法、后勤保障

3、情感型配角

- 红颜知己：情感支撑、心灵慰藉、感情线
- 兄弟/闺蜜：生死之交、搞笑担当、情感羁绊
- 宿敌/对手：互相成就、推动成长、最终和解

4、功能型配角

- 引路人：初期引导、世界观介绍、任务发布
- 垫脚石：衬托主角、被打脸对象、实力参照
- 传声筒：代替读者提问、信息补充、反应代表

5、个性型

- 逗比搞笑：插科打诨、自嘲解围、气氛担当
- 高冷禁欲：寡言少语、实力说话、偶尔破防
- 中二热血：自我设定、夸张言行、意外靠谱
- 傲娇别扭：口是心非、嘴硬心软、反差萌

## 配角设计原则

1. 每个配角必须有明确功能（推动剧情/衬托主角/提供信息/情感支撑）
2. 配角有自己的生活和故事，不只是主角的附属
3. 配角数量控制在可驾驭范围内
4. 重要配角需要有弧光

## 功能模型详解

### 忠诚护卫型

- 功能：战斗辅助、情感羁绊、牺牲高光
- 性格特征：忠诚、直率、重义
- 弧光方向：从跟随者到独立战士
- 经典范例：各种主角的兄弟/护卫

### 军师谋士型

- 功能：策略规划、信息分析、剧情推动
- 性格特征：聪明、谨慎、有时过于算计
- 弧光方向：从算计到真心
- 经典范例：诸葛亮式谋士

### 亦敌亦友型

- 功能：实力参照、互相促进、戏剧张力
- 性格特征：骄傲、有原则、实力强
- 弧光方向：从对手到盟友
- 经典范例：佐助式对手

### 红颜知己型

- 功能：情感支撑、剧情催化剂、读者代入
- 性格特征：温柔/活泼/冷艳，与主角互补
- 弧光方向：从旁观到并肩
- 注意：避免工具人化，给独立故事线
