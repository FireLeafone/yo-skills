# 人物风格特点设计

风格特点是角色的可辨识外显信号：口头禅、语言习惯、习惯性动作、标志性外物。它们不是贴在人物上的装饰，而是性格、经历和心理机制的直接外显，同时必须服从小说的题材与叙事风格。

## 生成链条：性格 → 心理机制 → 外显言行

每个风格特点都要能回答"为什么是这个"。链条缺一环，特点就只是噱头。

| 性格/经历 | 心理机制 | 外显风格特点 |
|-----------|----------|--------------|
| 谨慎稳健 | 对失控的恐惧 | 口头禅"再核一遍"；做重大决定前擦拭随身旧物 |
| 傲娇别扭 | 渴望认同又羞于承认 | 关心人时先骂一句"笨蛋"；说完狠话耳根发红 |
| 老阴比 | 永远留后手的习惯 | 从不把话说满："也不一定""看情况嘛" |
| 高冷禁欲 | 情绪表达被长期压制 | 情绪波动时反而更慢更轻；用转身代替回应 |

反推同样成立：先想到一个亮眼的口头禅，再问它暴露了什么心理机制、需要什么性格支撑；答不上来就砍掉。

## 四类可辨识信号

1. **口头禅与语言习惯**
   - 句式习惯：长句/短句、爱反问、爱打比方、从不下结论。
   - 称呼体系：对不同人物怎么称呼、何时换称呼；称呼变化本身就是关系信号。
   - 用词质感：敬语/粗口/行话/方言/文白程度，对应身份与时代。
   - 情绪信号：说谎、心虚、得意时语言习惯怎么变、什么不变。
2. **习惯性动作**
   - 分场景设计：思考时、紧张时、说谎时、得意时、动怒时各做什么。
   - 最好与身体特征、职业、旧伤或重要记忆挂钩，让动作自带来历。
   - 动作要能写进正文反复出现，而不是一次性描写。
3. **标志性外物**
   - 随身物品、穿着习惯、气味、声音。外物可承载伏笔与身世线索。
4. **行为仪式**
   - 决策与待人的固定程序，如"动手前必先敬酒""骂人从不带脏字"。

## 与小说风格对齐

- **题材语感**：玄幻/仙侠/历史角色避免现代口癖（"OK""没毛病"），都市轻小说可以口语化。判断标准：这句话放进本书任何一章都不出戏。
- **叙事基调**：轻松向可夸张放大，严肃向要克制内敛；悲剧向的口头禅越日常，破防时越狠。
- **群像区分度**：把几个主要角色的对白去掉名字混在一起，读者应能认出谁是谁；做不到就说明声纹重叠。
- **与既有风格档案对齐**：项目存在 novel-style 产出的写作手册或人物声纹表时，角色的风格特点必须与之同调，不得冲突。

## 数量与使用频率

1. 每个主要角色：1 个核心口头禅 + 2–3 个习惯性动作；配角 1 个即可，纯功能配角不需要。
2. 口头禅不是复读机：在关键节点出现才有记忆点，日常对白用变体或省略。
3. 保留核心结构做变体："我说过多少次了……"在训斥、恳求、自嘲三种情绪下应是三种说法。
4. 习惯动作同样分强度：紧张时摩挲戒角，崩溃时是死死攥住，放下执念后是取下戒指。

## 与人物弧光联动

风格特点是展示人物变化最省笔墨的方式，按弧光阶段演化：

- **破防时刻**：口头禅说不出口、习惯动作僵在半空，是内心崩塌的外证，比直接写心理独白更有力。
- **蜕变外证**：成长后换掉口头禅或戒掉旧习惯；负面弧光则是特点变味（口头禅从自嘲变成真心狠话）。
- **平坦弧光**：主角的特点从头到尾不变，恰好用来反衬他人和世界的改变。
- 设计弧光时在变化节点标注"风格特点在此如何变"，供写正文时直接执行。

## 落盘格式

写入 `presets/characters.md` 时，在角色档案中用固定小节记录：

```markdown
### 风格特点
- **核心口头禅**："再查一遍。"（源自一场因轻信酿成的旧祸）
- **口头禅变体**：训斥下属时"你自己再查一遍"；自责时"……我又没做好。"
- **习惯性动作**：
  - 思考时：用拇指摩挲刀鞘缺口
  - 说谎时：语速放慢，视线落在对方眉心
  - 动怒时：反而先笑
- **称呼体系**：对外称全名示警，称表字示好
- **弧光联动**：终章面对同类旧祸时首次说出"不用查了"，标志放下当年的自责
```

每条都要能反推出性格或经历；写不出反推的条目删掉。
