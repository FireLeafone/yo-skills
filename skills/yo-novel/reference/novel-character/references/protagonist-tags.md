# 主角性格标签详解

## 主角性格标签库（60+）

1、力量型

- 杀伐果断：决策迅速、行动果决、不拖泥带水
- 霸道强势：掌控一切、不容置疑、王者气场
- 热血冲动：一往无前、越战越勇、永不言败
- 国术无敌：拳拳到肉、以力破巧、武道巅峰

2、智慧型

- 老阴比：表面和善、暗中算计、永远留后手
- 腹黑深沉：心思缜密、布局深远、笑里藏刀
- 谨慎稳健：步步为营、不冒风险、厚积薄发
- 智商碾压：洞察一切、算无遗策、运筹帷幄

3、个性型

- 逗比搞笑：插科打诨、自嘲解围、气氛担当
- 高冷禁欲：寡言少语、实力说话、偶尔破防
- 中二热血：自我设定、夸张言行、意外靠谱
- 傲娇别扭：口是心非、嘴硬心软、反差萌

4、情感型

- 病娇偏执：爱到极致、不择手段、占有欲强
- 疯批美人：行事疯狂、魅力惊人、不可预测
- 温润如玉：温和有礼、内心坚定、以柔克刚
- 洒脱不羁：随性而为、不受束缚、快意人生

5、信念型

- 理想主义：坚守信念、不妥协、为理想而战
- 现实主义：审时度势、灵活变通、目标导向
- 反英雄：不择手段、灰色道德、自有底线
- 圣母/烂好人：善良过度、以德报怨、成长蜕变

6、特殊型

- 淡泊超然：不争不抢、实力超群、偶尔出手
- 邪魅狂狷：亦正亦邪、魅力四射、行事出格
- 双面人格：表里不一、身份切换、反差巨大
- 佛系躺平：不争不抢、被动成长、意外崛起

## 标签组合原则

1. 核心标签1-2个（决定主角基本性格）
2. 辅助标签1-2个（增加层次感）
3. 隐藏标签0-1个（反差/成长空间）
4. 标签间不能矛盾（除非刻意设计双面人格）

## 热门标签组合

| 组合 | 效果 | 适用题材 |
|------|------|---------|
| 杀伐果断+谨慎稳健 | 该出手时绝不犹豫，不该出手时稳如老狗 | 玄幻/仙侠 |
| 逗比+智商碾压 | 表面搞笑实则深谋远虑 | 都市/玄幻 |
| 高冷+反差萌 | 偶尔破防的冰山 | 言情/都市 |
| 病娇+温润 | 温柔外表下的偏执 | 言情/耽美 |
| 老阴比+杀伐果断 | 算计完再动手 | 仙侠/权谋 |
| 洒脱+实力超群 | 不争而自得 | 仙侠/武侠 |

## 标签深度开发

每个标签不只是表面特征，需要深入到：

- 行为模式：这个标签如何影响日常行为
- 决策逻辑：这个标签如何影响关键抉择
- 人际关系：这个标签如何影响与他人的互动
- 成长空间：这个标签有哪些可以发展/改变的方向
